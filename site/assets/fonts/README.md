# Cormorant Garamond

Fontes locais, obtidas em 21/09/2026 pela API oficial do Google Fonts, sem modificações. Licença SIL Open Font License 1.1 em [OFL.txt](./OFL.txt). Copyright 2015 the Cormorant Project Authors.

- Família: Cormorant Garamond.
- Estilos: normal e itálico; intervalo de pesos solicitado: 400–600.
- Subconjunto: **latin**, que inclui os caracteres precompostos usados em português-BR. Não são carregados subconjuntos cirílicos, vietnamita ou latin-ext.
- Formato: WOFF2, servido localmente. Arquivos somam 76.900 bytes (~75 KiB).
- Recomenda-se `font-display: swap` e Georgia como fallback; nenhum acesso ao Google Fonts é necessário em produção.
